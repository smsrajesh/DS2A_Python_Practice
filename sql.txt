Day_4 : 03-08-2026 :Today's SQL Questions:  



Question 1 – Employees Earning More Than Their Manager

Concepts to think about:

This is a Self Join.
The Employee table plays two roles:
Employee
Manager
Join the table with itself using the employee's manager_id and the manager's emp_id.
After joining, compare:
Employee salary
Manager salary
Return only the employee details.

Ask yourself:

"How do I get the manager's salary when it is stored in the same table?"

Question 2 – Highest Salary in Each Department

Concepts to think about:

Use the DENSE_RANK() window function.
Partition the data by department.
Order each partition by salary in descending order.
Employees with the highest salary should receive rank 1.
If multiple employees have the same highest salary, they should all appear.
If you need the department name, think about whether another table (like Department) needs to be joined.

Ask yourself:

"Can I first assign ranks to employees within each department, then keep only rank = 1?"
